# APEXION MOTORSPORT

**Engineered to Chase the Limit.**

Independent concept-stage motorsport design and engineering website.

## Website

The bilingual English/Greek static website is in [index.html](index.html). It is responsive and needs no build process, framework, or server.

### Sections

- **APEXION A1:** formula-style single-seater racing concept.
- **Products:** A1, AERO, POWER and SIM concept research directions.
- **Technology:** aerodynamics, vehicle dynamics and data intelligence.
- **Roadmap:** a phased research-to-prototype pathway.
- **Contact:** link to this GitHub repository.

### Publish with GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. The expected URL after successful publication is:

https://panagiotagrosdouli.github.io/APEXION-MOTORSPORT/
